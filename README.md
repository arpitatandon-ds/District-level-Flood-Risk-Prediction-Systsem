# District-level Flood Risk Prediction System

A machine learning web app that predicts flood risk at the district level. It is built with Streamlit and includes user login, single and batch (CSV) predictions, downloadable reports, and a Gemini-powered help chatbot.

## Features

- **User authentication**: login and signup before using the app
- **Single prediction**: enter district-level inputs and get the predicted flood risk
- **Batch prediction**: upload a CSV with multiple districts and get predictions for all of them at once
- **Report generation**: download the prediction results as a report
- **AI help chatbot**: ask questions about the app and flood risk, powered by Google Gemini

## Tech Stack

- **Language**: Python
- **Web app**: Streamlit
- **ML / data**: scikit-learn, pandas, NumPy
- **Chatbot**: Google Gemini API

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/arpitatandon-ds/District-level-Flood-Risk-Prediction-Systsem.git
cd District-level-Flood-Risk-Prediction-Systsem
```

### 2. Create a virtual environment and install dependencies

```bash
python -m venv venv

# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Set up the Gemini API key

Get a free API key from [Google AI Studio](https://aistudio.google.com/), then copy the example file and add your key:

```bash
# Windows
copy app\.env.example app\.env
# macOS / Linux
cp app/.env.example app/.env
```

Open `app/.env` and set:

```
GEMINI_API_KEY=your_key_here
```

> `.env` is listed in `.gitignore`, so your key is never pushed to GitHub.

### 4. Prepare data and train the model

The trained model file (`flood_model.pkl`) is not stored in the repository, so generate it first:

```bash
python scripts/data_preprocess.py
python scripts/train_model.py
```

### 5. Run the app

```bash
streamlit run app/app.py
```

The app opens in your browser at `http://localhost:8501`.

## Usage

1. Sign up or log in.
2. Choose between a single prediction or a batch CSV upload.
3. View the predicted flood risk and download the report.
4. Use the chatbot if you need help with the app.

## Notes

- User accounts are stored locally in `users.json`, which is not tracked by Git.
- If the model file is missing, run `python scripts/train_model.py` before starting the app.
- The chatbot needs an internet connection and a valid Gemini API key.
